PRACTICAL NETWORKING SKILLS

Networking Labs & Technical Commands.

Examples of networking commands and diagnostic techniques I've practiced while learning Cisco and Alcatel networking environments.

LAB 01

VLAN Verification

Inspect VLAN information and identify configured network segments.

Alcatel CLI · Lab Example 
-> show vlan

VLAN  Name         Status
----  -----------  -------
1     Default      Enabled
10    Office       Enabled
20    Guest        Enabled
30    Management   Enabled

Used to review VLAN IDs and confirm the presence of expected VLAN configurations.

LAB 02

Interface Status

Review switch port status and connectivity information.

Alcatel CLI · Lab Example 
-> show interfaces status

Port     Speed   Duplex   Status
-------  ------  -------  ------
1/1/1    1000    Full     Up
1/1/2    1000    Full     Up
1/1/3    Auto    Auto     Down
1/1/4    1000    Full     Up

Helps identify active interfaces and investigate potential connectivity issues.

LAB 03

Neighbor Discovery

Identify devices connected to switch interfaces using LLDP.

Alcatel CLI · Lab Example 
-> show lldp remote-system

Local Port : 1/1/1
Remote ID  : LAB-AP-01
Remote Port: Gi0
Device Type: Access Point

Neighbor discovery information can support switch port mapping and network documentation.

LAB 04

Connectivity Testing

Check whether a network device responds consistently to ping.

Windows CMD · Lab Example 
C:\> ping 192.0.2.10 -t

Reply from 192.0.2.10:
bytes=32 time=2ms TTL=64

Reply from 192.0.2.10:
bytes=32 time=1ms TTL=64

Continuous ping testing can help observe connectivity and identify intermittent network interruptions.
